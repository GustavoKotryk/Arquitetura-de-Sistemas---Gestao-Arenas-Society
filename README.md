# Projeto Gestão Arenas Society

## Descrição do Projeto
Este projeto é um sistema de gestão destinado à administração de arenas esportivas, permitindo o cadastro de eventos, reservas de horários, gestão de usuários e muito mais.

## Funcionalidades
- Cadastro de Arenas
- Gestão de Eventos
- Reserva de Horários
- Cadastro e Gerenciamento de Usuários
- Relatórios Estatísticos

## Stack Tecnológica
- **Frontend:** React, Redux
- **Backend:** Node.js, Express
- **Banco de Dados:** MongoDB
- **Autenticação:** JWT
- **Hospedagem:** Heroku

## Como Começar
1. Clone o repositório:
   ```bash
   git clone https://github.com/GustavoKotryk/Arquitetura-de-Sistemas---Gestao-Arenas-Society.git
   cd Arquitetura-de-Sistemas---Gestao-Arenas-Society
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Execute o aplicativo:
   ```bash
   npm start
   ```
